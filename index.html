Назначение

Расширение показывает время, записанное в задачах Bitrix24, названия задач и проектов, комментарии к записям, а также отчёты, доступные пользователю по его веб-хуку.

Какие данные обрабатываются

Адрес и токен персонального REST-веб-хука Bitrix24, профиль сотрудника (включая ФИО), идентификаторы задач и пользователей, сведения о проектах, времени и комментариях к задачам, настройки интерфейса, нормы рабочего времени и вручную отмеченные отсутствия. При наличии необходимых прав у веб-хука полная аналитика может обрабатывать данные других сотрудников, к которым этот веб-хук имеет доступ.

Передача и хранение

Расширение выполняет прямые HTTPS-запросы к тому порталу Bitrix24, адрес которого указал пользователь в веб-хуке. Веб-хук и настройки сохраняются в локальном хранилище Chrome на устройстве пользователя; полная версия может также сохранять введённый веб-хук в локальном хранилище своей страницы. Расширение не отправляет эти данные на отдельный сервер разработчика и не продаёт их третьим лицам. Данные обрабатываются Bitrix24 как используемым пользователем сервисом.

Уведомления

Если пользователь включит уведомления, расширение периодически обращается к Bitrix24 и создаёт локальные уведомления о проверке записей рабочего времени. По умолчанию уведомления выключены.

Контроль и удаление

Пользователь может заменить веб-хук в настройках, очистить данные расширения в настройках Chrome либо удалить расширение. Отдельно сохранённый в полной аналитике веб-хук удаляется через её команду «Забыть».

Безопасность

Доступ к данным определяется правами веб-хука Bitrix24. Пользователь не должен передавать веб-хук третьим лицам; токен предоставляет доступ к разрешённым ему методам API. Данные передаются к порталу по HTTPS.

Ограничение использования данных

Полученные данные используются только для отображения и анализа рабочего времени, задач и связанных с ними уведомлений. Данные не используются для рекламы, профилирования или перепродажи.
